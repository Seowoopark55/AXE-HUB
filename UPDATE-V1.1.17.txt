AXE HUB · AXE BUILD V1.1.17
=================================

[카테고리 분류]
- 카테고리는 오로지 작성자가 선택한 태그만 기준
- 개조서에 체력 옵션이 들어 있어도 '체력' 태그가 없으면 체력 카테고리에 표시되지 않음
- 이동속도 + 체력처럼 복합 빌드는 두 태그를 직접 선택하면 양쪽에 표시

[생활 카테고리]
- 생활 전체: '생활' 또는 벌목/낚시/채광/택배 태그가 있는 빌드
- 생활 세부: 해당 세부 태그를 직접 선택한 빌드만 표시

[개조서 자동 분석]
- 선택한 개조서에서 체력/이동속도/생활 계열 등을 감지
- 단, 자동 분류하지 않음
- 작성 화면에서 추천 태그 버튼으로만 제안
- 작성자가 버튼을 눌러야 실제 태그에 추가

[검색]
- 세팅명 / 태그 / 작성자뿐 아니라
  선택된 개조서 이름 / 분류 / 옵션 내용도 검색 가능

Supabase / SQL 변경 없음.
