AXE HUB · AXE BUILD V1.1.6
=================================

[우측 패널 일체형 개편]
- 왼쪽 고정 리모컨 제거
- 우측 패널에 모집 안내 + 빠른 메뉴(홈/공지/제보/내 프리셋) 통합
- 공지 개수 배지 유지
- 현재 탭 상태를 보여주는 안내 카드 추가

[모집 안내 팝업]
- 우측 패널의 "모집안내" 버튼 클릭 시 제공받은 AXE 모집 포스터 팝업 표시
- DM 문의 링크가 설정돼 있으면 팝업 안에서 바로 이동 가능

[장비 세팅 배경]
- 추천세팅 상세 장비 보드에 실제 인게임 배경 이미지 적용
- 내부용 느낌을 유지하면서 더 리얼한 장비 화면 연출

[반응형]
- 화면이 충분히 넓을 때만 우측 패널 노출
- 좁은 화면에서는 본문 가독성 우선

Supabase / SQL 변경 없음.
