AXE HUB · AXE BUILD V1.1.9
=================================

이번 버전은 슬롯 UI만 집중 수정한 버전입니다.

[데스크톱]
- 옵션창이 항상 떠 있는 방식 제거
- 기본 상태에서는 장비 4개만 깔끔하게 보임
- 겉옷 / 상의 / 하의 / 신발에 마우스를 올릴 때만 옵션 패널 표시
- 다른 장비로 바로 마우스를 이동하면 옵션 내용도 즉시 교체
- 장비 영역을 벗어나면 옵션 패널 자동 숨김
- 옵션 패널은 슬롯판 내부의 전용 영역에서 팝업되므로 잘림 현상 없음
- 옵션 패널은 pointer-events:none
  → 팝업이 다음 장비 Hover를 막는 문제 없음
- Hover 중인 장비만 골드 테두리 강조

[모바일]
- Hover가 없으므로 기존처럼 장비 클릭으로 상세 옵션 확인

그 외 기능 / Supabase / SQL 변경 없음.
