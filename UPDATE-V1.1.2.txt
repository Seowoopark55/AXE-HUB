AXE HUB · AXE BUILD V1.1.2
=================================

이번 버전은 사용자가 제공한 실제 AXE NET 전체 파일을 직접 분석해서
내부 추천세팅의 마크업/배치/hover 안정화 로직을 외부용에 이식한 버전입니다.

[리모컨]
- 'AXE 인원모집 중 / DM 문의 주세요.'를 리모컨 최상단 헤더로 통합
- 아래 버튼: 홈 / 공지 / 제보 / 내 프리셋
- 기존 별도 모집 박스 제거
- 모바일에서는 헤더를 숨기고 4버튼 하단 바 유지

[상단 카테고리]
- 공지를 가장 왼쪽으로 이동
- 공지 → 추천세팅 → 내 프리셋 → 개조서 → 제보 순서

[추천세팅 상세]
AXE NET의 실제 내부 구현을 기준으로 재작성:
- 인벤토리 상단바
- 실제 게임 인벤토리처럼 보이는 ghost slot 배경
- 겉옷 / 상의 / 하의 / 신발 정확한 내부 위치
- 부위별 서로 다른 장비 프레임 높이
- 장비 Hover 시 내부용과 같은 옵션 tooltip
- tooltip pointer-events:none 적용
  → 겉옷에서 상의/하의/신발로 바로 마우스를 움직여도
    이전 tooltip이 다음 장비 hover를 가로막지 않음
- Hover 시 다른 슬롯/ghost slot 페이드
- 접두 파랑 / 접미 붉은색
- 옵션 최대값 + 옵션명 + 실제 등장범위를 내부용과 같은 3열로 표시
- 오른쪽 MAX ROLL SUMMARY 내부용 구조 사용
- 주의 옵션 / 부위별 코멘트 내부용 구조 사용
- 모바일에서는 클릭한 부위의 옵션을 하단 고정 상세로 표시

[기존 외부용 기능 유지]
- 내 프리셋
- 추천 / 비추천
- 댓글
- 수정 / 삭제
- 공지
- 제보
- 닉네임 신청/승인

Supabase 추가 SQL 없음.
V1.1.0 마이그레이션까지 적용되어 있다면 그대로 사용합니다.
