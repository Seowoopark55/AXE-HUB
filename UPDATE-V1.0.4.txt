AXE HUB · AXE BUILD V1.0.4
=================================

핵심 수정
- 메인의 '놀 땐 놀고, 일할 땐 하는 회사' 대형 배너 완전 제거
- 추천세팅 상세의 '인벤토리' 탭 제거 → 장비 구성으로 단순화
- 장비 이미지의 01 / 02 / 03 / 04 숫자 태그 제거
- 선택한 접두/접미 개조서의 실제 옵션 문구를 장비 바로 아래에 표시
- 접두(파랑) / 접미(보라) 시각 구분 추가
- 전체 옵션 요약과 개조서 옵션 텍스트 크기 확대
- 추천세팅 작성 화면에서도 접두/접미 색상 구분 및 선택 옵션 미리보기
- 본인 작성 세팅 및 관리자에게 '수정 / 삭제' 버튼 제공
- 수정 시 기존 글/슬롯을 실제 UPDATE
- 삭제 시 확인창 후 실제 DELETE
- 하단 모집 영역을 세로로 긴 포스터형에서 짧은 가로 배너형으로 재구성
- 제공받은 AXE 와이드 브랜드 배너 + 모집 포스터를 배너 안에서 함께 활용

DB 스키마 변경 없음.
기존 RLS / 권한 정책을 그대로 사용합니다.

적용
1. 기존 프로젝트 폴더에 ZIP 내용 전체 덮어쓰기
2. .env.local 유지
3. GitHub Commit → Push
4. Vercel 자동 배포
