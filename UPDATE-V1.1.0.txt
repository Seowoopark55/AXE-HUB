AXE HUB · AXE BUILD V1.1.0
=================================

이 버전은 DB 기능 확장이 있으므로 반드시 먼저 SUPABASE-MIGRATION-V1.1.0.sql을 AXE HUB SQL Editor에서 실행하세요.

핵심
- 하단 대형 모집 배너 삭제
- 우측 고정 리모컨형 홍보/공지/제보/내 프리셋 메뉴
- 장비는 이미지 중심, 마우스 오버 시 개조서 옵션 팝업
- 접두 파랑 / 접미 붉은색
- 옵션 미선택이어도 슬롯 높이 균형 유지
- 주의 옵션 가독성 확대
- 추천 / 비추천 / 댓글 기능
- 기존 favorites를 사용자 UI에서 '내 프리셋'으로 정식 사용
- 메인/상단에서 내 프리셋 진입 강화
- 공지사항 + 관리자 공지 등록/삭제
- 닉네임 신청 / 관리자 승인·반려
- 닉네임 승인 시 기존 글/댓글 작성자 이름도 갱신
- 제보 메뉴와 CTA 강화
- V1.0.4에서 불안정했던 본인 글 수정/삭제 RLS 정책 보강

적용 순서
1) SUPABASE-MIGRATION-V1.1.0.sql 실행
2) ZIP 내용 전체를 기존 GitHub 프로젝트에 덮어쓰기
3) .env.local은 유지하고 GitHub에는 올리지 않음
4) Commit → Push
5) Vercel 자동 배포 확인
