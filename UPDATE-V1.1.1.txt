AXE HUB · AXE BUILD V1.1.1
=================================

이번 버전은 추천세팅 상세 UI를 AXE NET 내부용의 최종 형태에 맞춰 재설계합니다.

핵심 변경
- 우측 고정 리모컨 확대
- 리모컨 구성: 홈 / 공지 / 제보 / 내 프리셋
- 리모컨에서 모집 포스터 제거
- 별도 작은 텍스트 영역으로:
  AXE 인원모집 중
  DM 문의 주세요.
- 추천세팅 상세:
  2x2 장비 이미지 + 고정 옵션 툴팁 + 전체 옵션 요약
- 개별 장비 위에 뜨는 오버레이 tooltip 제거
- 겉옷 → 상의 → 하의 → 신발로 커서를 바로 움직이면
  한 개의 고정 툴팁 내용이 즉시 교체됨
- tooltip이 다른 장비의 hover 영역을 가리지 않으므로 기존 stale hover 문제 방지
- 장비/옵션/전체요약을 데스크톱에서 최대한 한 화면에 표시
- 기존 V1.1.0의 추천/비추천, 댓글, 공지, 내 프리셋,
  닉네임 신청/승인 기능은 유지

Supabase SQL 추가 변경 없음.
V1.1.0 마이그레이션을 이미 실행했다면 SQL 재실행 필요 없음.

적용
1. 기존 GitHub 프로젝트 폴더에 ZIP 내용 전체 덮어쓰기
2. .env.local 유지
3. GitHub Commit → Push
4. Vercel 자동 배포
