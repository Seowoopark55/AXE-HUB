AXE HUB · AXE BUILD V1.1.4
=================================

[닉네임 승인 표시]
- 공지 페이지에서 관리자가 아니면:
  '닉네임 승인 기능은 관리자 계정에서만 표시됩니다.' 안내
- 사용자 프로필에 '관리자 / 일반 계정' 역할 표시
- 관리자 계정에서는 기존대로 닉네임 승인 바로가기와 관리 메뉴 노출

[좌/우 사이드 레일]
- 빠른 리모컨을 메인 컨텐츠 왼쪽으로 이동
- 구성 유지: 모집 헤더 / 홈 / 공지 / 제보 / 내 프리셋
- 기존 리모컨 자리(오른쪽)에 AXE 모집 홍보물을 고정 배치
- 홍보물은 스크롤을 따라오는 세로형 카드
- 모바일에서는 홍보물 숨김, 리모컨은 기존 하단 4버튼 바

[중요]
닉네임 승인 메뉴가 안 보이는 원인은 계정의 profiles.is_admin=false인 경우가 가장 유력합니다.
관리자 기능 자체를 숨기는 기존 보안 설계를 유지했습니다.

Supabase 추가 SQL 변경 없음.
V1.1.0 마이그레이션 적용 상태를 그대로 사용합니다.
