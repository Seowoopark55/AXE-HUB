# AXE BUILD v1.1.19 · AXE HUB

외부 공개용 추천세팅 / 개조서 / 제보 서비스입니다.

## V1.0.2 UI / 내부 추천세팅 UX 반영

- 메인 우측의 의미가 불분명한 장식 카드를 제거하고 **실제 공식 추천세팅 미리보기**로 교체
- 메인에서 **추천세팅 바로 보기 / 공식 세팅 보기 / 빠른 탐색** 제공
- 추천세팅 목록을 텍스트 카드에서 **겉옷·상의·하의·신발 슬롯형 카드**로 변경
- 개조서를 **목록 + 상세 도감형 UI**로 변경하고 부위 필터 추가
- 제보 화면에 **누락 → 수정 → 검수 반영** 흐름을 시각적으로 정리
- Discord 로그인 안내에 **서버 가입/메시지 접근 권한을 요청하지 않음**을 명시
- 기존 Supabase / Discord OAuth / 작성 / 복제 / 즐겨찾기 / 제보 / 관리자 기능 유지

## 적용

이 ZIP의 파일 전체를 기존 GitHub 저장소 루트에 덮어쓰기한 뒤 Commit 하면 됩니다.
GitHub와 Vercel이 연결되어 있으면 자동 배포됩니다.

`.env.local`은 GitHub에 올리지 않습니다.

Vercel 환경변수는 기존 값을 그대로 유지합니다.

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_KEY
VITE_SITE_URL=https://YOUR-SITE.vercel.app
VITE_AXE_CONTACT_URL=
```

**DB SQL 변경 없음.** 기존 AXE HUB Supabase를 그대로 사용합니다.

## V1.1.16

공개 배포 전 개인정보/업로드 안전장치를 정리했습니다.

- Discord OAuth 추가 scope를 `identify`만 요청하도록 변경했습니다.
- 첫 로그인 전에 AXE BUILD가 요청하는 정보와 요청하지 않는 정보가 보이는 로그인 안내를 추가했습니다.
- Discord 비밀번호, 서버 채팅, DM, 서버 목록에는 접근하지 않는다는 점을 명시했습니다.
- 제보 증빙 이미지는 PNG/JPG/WEBP만 허용하고 최대 5MB로 제한했습니다.
- 저장 파일 확장자는 원본 파일명이 아니라 브라우저가 확인한 MIME 타입을 기준으로 생성합니다.
- 업로드 시 `contentType`을 명시합니다.
- Vercel에 `nosniff`, `DENY frame`, Referrer-Policy, Permissions-Policy 등 기본 보안 헤더를 추가했습니다.

**V1.1.16 자체의 새 SQL은 없습니다.**
단, V1.1.15 회사명 기능을 사용하려면 기존 `SUPABASE-MIGRATION-V1.1.15.sql`이 적용되어 있어야 합니다.


## V1.1.17

추천세팅 카테고리 분류 기준을 명확하게 정리했습니다.

- `무법지대 / 체력 / 이동속도 / 생활` 카테고리는 **작성자가 직접 선택한 태그만** 기준으로 분류합니다.
- 예를 들어 `이동속도` 태그만 선택한 빌드에 체력 개조서가 포함돼 있어도 체력 카테고리에는 노출되지 않습니다.
- `체력 + 이동속도` 빌드라면 작성자가 두 태그를 모두 선택해야 두 카테고리에 노출됩니다.
- 생활 세부 카테고리 역시 `벌목 / 낚시 / 채광 / 택배` 태그를 직접 선택한 경우에만 해당 세부 분류에 노출됩니다.
- 선택한 개조서는 카테고리를 자동 변경하지 않고, 작성 화면에서 **추천 태그**만 제안합니다.
- 추천 태그는 `+ 체력`, `+ 이동속도`처럼 버튼을 눌러 작성자가 직접 추가해야 적용됩니다.
- 빌드 검색에서는 개조서 이름/분류/옵션까지 계속 검색할 수 있습니다.

SQL 변경 없음.


## V1.1.18

외부 공개 운영을 위한 서버단 도배 방지 장치를 추가했습니다.

- 빌드 작성: **10분 3개 / 24시간 15개**
- 댓글: **1분 5개 / 24시간 80개**
- 제보: **10분 3개 / 24시간 12개**
- 관리자 계정은 제한에서 제외됩니다.
- 제한은 브라우저 버튼이 아니라 **Supabase DB Trigger에서 Discord 로그인 사용자 UUID 기준**으로 검사합니다.
- 병렬 요청으로 제한을 우회하기 어렵도록 사용자/행동별 DB advisory lock을 사용합니다.
- 제한에 걸리면 `약 N분 후 다시 시도해주세요`처럼 남은 대기시간을 알려줍니다.
- 같은 빌드 내용은 24시간 내 중복 게시를 차단합니다.
- 같은 빌드에 같은 댓글을 연속 등록하는 것을 차단합니다.
- 동일한 제보 내용은 24시간 내 중복 등록을 차단합니다.
- 제보 이미지가 먼저 업로드된 뒤 DB 등록이 차단된 경우 프론트에서 해당 업로드 파일 삭제를 시도합니다.

**V1.1.18은 `SUPABASE-MIGRATION-V1.1.18.sql` 1회 실행이 필수입니다.**
